### Added

- Initial public release: HTTP(S) monitors with keyword and status-code checks
- SSL certificate expiry tracking with configurable warnings
- Uptime and response-time statistics over 24 hours, 7 days and 30 days
- Organizations with isolated data, team invitations and owner and member roles
- Telegram alerts through a bot, with contact binding via deep link
- JSON API for monitor status
- Docker image, Docker Compose setup, and GitHub Actions CI
